# Enlaces a mano para nombres LOCALES de los fragmentos de src/matched (A, D0, f1...): el C byte-match

# Formato: XXXXXXXX nombre func|data 0xDIRECCION    (XXXXXXXX = direccion del fichero f_XXXXXXXX.c)
# Cada linea se saca del desensamblado de esa funcion en el ELF del usuario (solo lectura).
